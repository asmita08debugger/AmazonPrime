# Amazon Prime Video Clone

A full-stack streaming platform website inspired by Amazon Prime Video.

## Features

- User registration and login
- Secure password hashing
- Session-based authentication
- Movie and TV show catalog
- My List / Watchlist
- Add movies and shows to My List
- Remove movies or shows from My List
- SQLite database
- Flask backend
- Responsive streaming-platform style interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## How to run:

  - Clone the repository
  - Open the project folder in VS Code
  - In the VS Code terminal type : python app.py
  - Then open using this link in your browser : http://127.0.0.1:5000/
